# RÖ Social Landing Page

This is a static, mobile-friendly social landing page for RÖ.

## Free hosting with GitHub Pages

1. Create a new GitHub repository, for example `ro-social-page`.
2. Upload all files in this folder, keeping the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a free public URL.

Once the page has a permanent URL, that URL can be turned into the single QR code for all RÖ social accounts.
